北海道開発局 函館開発建設部　令和7〜8年度施行（知内町・福島町・松前町・上ノ国町）

一般国道228号 知内町 重内橋補修外一連工事　施工工程表（案）

幸連橋・重内橋・神馬橋（右歩道）・原口大橋・初神大橋・寅の沢橋の6橋をまとめた、考えられる施工手順と工程です。日数は見積参考資料の人工（1か所・1m²あたり）を、私が仮定した班の人数で割って出したものです。表の中の数字を書き換えると工程が引き直されます。

施工手順

  1. 準備（施工計画・協議・現地計測）

    6橋は知内町から上ノ国町まで約100km離れています。工程に影響する協議として、幸連橋・初神大橋の河川協議（R7.10）、原口大橋・寅の沢橋の河川協議（R7.11）、上磯漁組（重内橋・幸連橋）、松前さくら漁組（原口大橋・初神大橋）、ひやま漁組（寅の沢橋）が特記仕様書に挙がっています。詳細設計の完了は幸連橋・初神大橋・原口大橋・寅の沢橋・神馬橋とも R7.11 です。

    設計図書の見込み：準備60日・後片付け20日・雨休率0.70／完全週休2日（土日）／令和7年度の出来高予定額を満たす時期に着手すること（特記仕様書）

    補修図はどれも「詳細寸法は現地計測後に決定」です。当て板や補剛材は現地計測のあとで製作するので、計測→製作→取付けの順が工程の芯になります。足場は従来のパイプ足場とシステム足場などを比べて工法を協議します（設計変更の対象）。

  2. ［幸連橋］吊足場 → G2 の当て板補修 → 塗装塗替

    G2 の下フランジに当て板（t=10・14mm、高力ボルト66組、現場孔明66孔）を添え、b部の垂直補剛材を一部切断して取り替えます。そのあと剥離剤で旧塗膜を除去し、Rc-Ⅰ（有機ジンクリッチ＋下塗2回＋中塗＋上塗）で G2 の 12.538m を塗り替えます（57m²）。

    吊足場 70m²（供用0.5月）＋中段足場 110m²（ブラスト・剥離養生シート、供用2.1月）／当て板 1か所（世話役10・特殊工30・普通作業員10 人日）／塗替 57m²

    塗替えには気温と湿度の制約があります（塗装間隔 1日〜10日）。旧塗膜の鉛などに備えた呼吸用保護具の費用は未計上です（特記仕様書）。

  3. ［幸連橋］排水管の取替え・床版水抜きパイプ

    排水管 8か所（ポリエチレン管φ165 L=2.10m、取付金具、アンカー32本、2箇所×4タイプ）／床版水抜きパイプ 10か所（削孔φ53、フレキシブルチューブ21m、桁クランプ10個）

  4. ［幸連橋］橋面防水と舗装の打換え（片側交互通行）

    L側の歩車道境界ブロック（48m）を外し、舗装を切って取り壊し、塗膜防水（98m²）と導水パイプを入れて、細密粒度ギャップアスコン（改質Ⅱ型）で戻し、ブロックを再設置します。

    舗装版切断 98m・破砕 40m²／防水 98m²・導水パイプ 99m・目地 101m／アスコン t=3〜6cm 計65m²（51m²/日の施工見積）／殻 5t

    舗装は冬期を避けます。質疑応答で、R側補修箇所2層目の t=4cm にはタックコート（PKR-T）が必要と回答されています。

  5. ［重内橋］桁端の当て板補修（4か所）

    A1G1・A1G3 は支点補剛材に山形の当て板、A1G4・A2G3 は下フランジ・ウェブ下端・支点補剛材に当て板を添え、ピンチプレートを取り替えます。A1G4 は沓座コンクリートのはつりと無収縮モルタルでの打ち直しがあります。

    吊足場 60m²（供用0.9月）／当て板 4か所（91人日）／沓座 0.01m³／現場塗装 F-11 1m²

  6. ［神馬橋 右歩道］ベントで仮受け → A2橋台の断面修復

    G11 の支承の下の欠けを、ジャッキとベントで桁を仮受けしてから、はつり・鉄筋防錆・ポリマーセメントモルタルで左官し、ケイ酸塩系含浸防水材を塗ります。

    ベント 1台（山留材 H200 0.2t、土のう7袋、20人日）／断面修復 0.009m³／含浸材 0.3m²／吊足場 10m²

    外気温が5℃以下になるときは、断面修復の養生に注意が要ります（断面修復工標準図）。

  7. ［原口大橋］吊足場 → 床版・地覆の断面修復

    延長135.6m（約574m²）の吊足場を掛け、床版下面と地覆の21か所をはつって左官します（Aタイプ 10か所・Cタイプ 11か所）。

    吊足場 580m²（両側朝顔、供用1.1月）／樹脂モルタル 0.03m³（220人日/m³）＋ポリマーセメントモルタル 0.04m³（130人日/m³）

  8. ［原口大橋］落下物防止柵のボルト交換（片側交互通行）

    2,120本（両側106m、1スパン20本）／80本あたり 世話役1・特殊作業員2・普通作業員1 人日 → 約27日

  9. ［初神大橋］枠組足場 → P1・P2 橋脚の断面修復・犠牲陽極材・ひびわれ注入

    P2 は基部から天端まで約34mあり、枠組足場（H≧30m）を組みます。断面修復（P1 1.0×0.8m、P2 3.45×2.2m・2.7×0.3m、t=50mm）、その縁に犠牲陽極材41個、P2 のひびわれ注入 1.2m。

    枠組足場 1,420m²（供用2.6月）／断面修復 0.5m³／犠牲陽極材 41個（20個あたり4人日）

  10. ［寅の沢橋］吊足場 → 水平補剛材の当て板補修 → フレキシブルチューブ

    1径間 G3・2径間 G1 の水平補剛材に、新しい山形鋼の補剛材を高力ボルトで添えてから既設を切断撤去します（60か所、622kg、ボルト264本）。床版水抜きの下にフレキシブルチューブ31か所（68m）。

    吊足場 450m²（供用2.5月）／当て板 部材①②④ 36か所・③⑤⑧⑨ 18か所・⑥⑦ 6か所（計約591人日）／チューブ 31か所

    この工事でいちばん人工の多い作業です。班の人数で日数が大きく変わるので、協力会社の班編成で置き換えてください（ここでは10人の班で60日としています）。

  11. 出来形の確認・後片付け

    出来形を確認し、現場発生品（鋼材・排水管）を江差道路事務所・松前防災ステーションへ運びます。道路施設基本データの作成があります。

確認しておきたい点

寅の沢橋の吊足場の供用月数（2.5月）と、当て板補修の人工（約591人日）が合いにくい

見積参考資料の当て板補修は 部材①②④ 1か所12人日×36、③⑤⑧⑨ 7.5人日×18、⑥⑦ 4人日×6 で、計約591人日です。2.5か月（実働約45日）で終えるには、毎日13人ほどが桁の下に入る計算になります。足場の供用月数と班の編成を、施工計画の段階で協議しておくと安心です。

  • 原口大橋の断面修復：総括表の「樹脂モルタル・鉄筋防錆処理有 0.03m³」は図面の Aタイプ（10か所、約1.12m²×30mm）と量が合いますが、断面修復工標準図では Aタイプの欄に×が引かれ、樹脂モルタルを使うのは Bタイプ（かぶり不足）です。図面の記号と材料のどちらに合わせるか確かめてください。
  • 断面修復材の規格：特記仕様書は「ポリマーセメントモルタル σ28=40N/mm²、t=5mm/層、1,875kg/m³ を想定」、図面（神馬橋・原口大橋）は σck≧24N/mm² です。質疑応答でも規格の確認が出ています。
  • 原口大橋の吊足場：参考図は延長135.6m・A=573.96m²、総括表は 580m²。
  • 寅の沢橋の吊足場 450m² は、橋の下の全面（48.5×9.2m＝446m²）と同じ大きさです。補剛材の補修は G1・G3 の外側だけなので、範囲を絞れるか検討の余地があります。
  • 幸連橋の当て板材：主桁補修図(1)(2)の新設数量を足すと SM490YB 約182kg・SM400A 約8kg、総括表は t10 66kg・t14 203kg・t8 19kg（計288kg）です。製作ロスや撤去材の扱いを確かめてください。
  • 幸連橋の高力ボルト：図面は M22×65 24組・M22×80 42組・M22×60 19組で、総括表（19・24・42組）と合います。
  • 重内橋の沓座コンクリート（0.01m³）の位置は、図面で特定できませんでした（3Dでは A1 の G4 に置いた目安）。
  • 神馬橋の図面は「右歩道」の A2 橋台だけです。車道橋（PC桁）は対象外です。
  • 未計上の費用（特記仕様書）：鉛等呼吸用保護具、鉄筋探査、油圧ジャッキ賃料、枠組足場（初神大橋）、集塵排気装置・簡易セキュリティールーム、ブラスト材、ひびわれ補修の低圧注入（初神大橋）、ボルト・ナット材料（原口大橋）ほか。設計変更で計上する場合があります。
  • 交通誘導警備員は概略数量で、片側交互通行時に A1名・B2名（交代1名）の配置で計上されています。6橋の合計は A45・B90 人日です。
  • 補修一般図には「マイクロや過年度業務、現地簡易計測で復元したもので、詳細寸法は現地計測のうえ確認」とあるものがあります（幸連橋・初神大橋）。
  • 日数は見積参考資料の人工を、私が仮定した班の人数で割ったものです（鋼橋の補修は世話役1＋特殊工3〜8、コンクリートは3〜4人）。協力会社の実績に置き換えてください。着手日と稼働率も仮の値です。
