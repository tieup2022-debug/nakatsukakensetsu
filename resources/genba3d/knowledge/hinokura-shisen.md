# 桧倉川支線 開設工事（SP1051〜SP1580）　回答用資料

R08-03桧倉（林業生産基盤整備道桧倉川支線開設工事）の 桧倉川支線 開設工事（SP1051〜SP1580） について、3Dモデル（2次元の設計図から組み立てたもの）と施工手順・工程表の画面に載っている内容です。

## 工事の概要

- 工事名：林業生産基盤整備道桧倉川支線開設工事（第551号、林道整備事業 令和7年度補正）。発注は北海道 渡島総合振興局 西部森林室。場所は松前郡福島町字桧倉
- 工期：2026年4月1日〜2027年1月29日（工事概要・計画工程表）。見積用説明書の工期は 令和8年3月27日〜令和9年1月29日
- 区間：令和7年度（補正）分の開設区間 SP1051〜SP1580（ブレーキ SP1289.98＝SP1285.09 を引いて約524m）。幅員4.0m、設計速度20km/h
- 工種：林道土工（掘削・盛土・路盤・法面整形・アスファルト表層）、法面工（植生）、擁壁工（補強土壁）、排水構造物工（素掘側溝・路面排水版・ヒューム管・集水桝・路床排水）、防護柵工（ガードケーブル・カーブミラー）、標識工、仮設工
- 進み具合：工事旬報の出来高は 9/30 で69%（計画工程表の9月末は63%）。掘削はほぼ終わり、補強土壁は 7/25 の法面崩壊で中断。7/30 に路線を山側へ寄せる設計変更案（路線スライド）が出て、協議中
- 図面は2次元のPDFとCADデータ（平面図・縦断面図・横断面図・作工図・作工模式図・標準図）で、3Dの設計データはない

## モデルの作り方と注意

- フォルダの図面（平面図・縦断面図・横断面図・作工図・標準図）は2次元のPDFとCADデータで、3Dの設計データはありません。
- 線形は平面図の曲線表（IP22〜IP35 の座標と半径）から計算しました。各曲線の始点・終点の測点は表と0.05m以内で合っています。SP1289.98＝SP1285.09（ブレーキ 4.89m）も入れています。
- 縦断面図の計画高と、横断面図（SP1040〜1600 の約90断面）の地盤線・計画線を座標で読み取り、測点ごとにつないでいます。横断図の左は、起点から終点を見て左（L）です。
- 地形は横断図の範囲（中心から左右およそ20m）だけです。断面の間は直線でつないでいるので、断面と断面の間の細かい起伏は省いています。
- ヘアピン（R=12・R=18）の内側は横断図どうしが重なるため、法面の一部を描いていません。
- 補強土壁は当初設計の位置です。路線スライドは 7/30 の設計変更案（横断面図 8-5）の寸法の位置から読んだずれで、確定した図面ではありません。
- 暗渠の深さと向き、路面排水版の角度、ガードケーブルの支柱間隔、機械の位置は目安です。
- 工事前の地盤は設計時の地盤線で、起工測量（UAVレーザー）の点群ではありません。

## 施工手順

1. 準備・伐開（施工済み）
   - 書類作成、現場事務所・仮設備の設置、起工測量（UAVレーザー）、仮道路の設置。人力伐開と伐木の集積・玉切りは 5/13〜6/25。伐根の産業廃棄物処分（28.82t）は 10/7 の協議簿で報告済みです。
   - 数量：段階確認：起工測量結果（4/27）／施工範囲等（伐開物処理前）
2. 掘削・積込・運搬 → 盛土 → 法面整形（ほぼ施工済み）
   - バックホウ（0.8m³）と大型ブレーカ（1,300kg級）で掘削し、土砂の一部は路体の盛土に流用、残りは指定の残土処理場（約13km）へ10tダンプで運んで整地します。切土法面 1:0.6〜1:0.8、盛土法面 1:1.5。
   - 数量：掘削 7,370m³（土砂1,900・軟岩5,470）／流用 1,440m³／残土 5,245m³＋すき取り土 409m³／盛土（路体）1,984m³／法面整形 切土797.2m²・盛土686.1m²
   - 留意点：旬報では 6/26 の夜の雨で SP1350 付近の土砂が下の道路まで流れ、7/16・7/18 の雨で SP1216・SP1533.69 の法面が崩れています。11月以降の雨と融雪で同じことが起きないよう、仮排水と法面の早めの保護を見込んでください。
3. ［変更区間］設計変更の協議 → 追加の切土（SP1300〜1400）
   - 補強土壁の掘削中（7/25）に法面が崩れ、7/30 に路線を山側へ寄せる案（路線スライド）が出ています。変更の横断面図では、路面が SP1317〜1393 で山側へずれ、最大は SP1340 の約5.0m です。
   - 数量：追加の切土 約2,731m³（土量計算表 SP1300〜1400）／ここでは 1日あたり約180m³（軟岩を含む）として15日
   - 留意点：変更が決まる日が工程全体を左右します。上の「設計変更が決まる日（仮）」を実際の日に合わせてください。
4. ［変更区間］補強土壁（SP1342.80〜1369.20 右、L=26.40m）
   - 床掘して基準高を確認（段階確認）し、基盤排水層・背面の有孔管を据えてから、鋼製の壁面ユニット（1:0.3）を組み、ジオグリッドを敷いて盛土を1層ずつ締め固めて積み上げます。
   - 数量：壁面積137.44m²／鋼製ユニット206セット／ジオグリッド 30kN/m 330.2m²・37kN/m 332.6m²・安定補助材148.3m²／水平排水材56.1m／暗渠排水管 57.2m／キャットウォーク201.4m・安全柵23.4m
   - 留意点：発注者の計画工程表では補強土壁は約30日（8/20〜9/30）。盛土材の土質試験を施工前に行うこと（図面の特記事項）。凍った土で盛土しないよう、冬期に入る場合は時期を協議してください。
5. 排水（暗渠・側溝・路面排水版）
   - 第12号（SP1321.5 φ600）は 7月と9月、第11号（SP1223.5 φ450）は 9/28〜10/2 に施工。U型トラフ（U300B）は 6/29〜7/3、素掘側溝は 7月・9月末〜10月に施工しています。残りは第13号（SP1426 φ450）と集水桝、路面排水版。
   - 数量：ヒューム管 φ450 14.6m・φ600 12.2m／集水桝 Ⅰ型A 2基・Ⅰ型B 1基／路面排水版 6個／素掘側溝 64m
6. 路盤 → アスファルト表層
   - 路床を仕上げて上層路盤（再生骨材 0〜40mm）を敷き、締め固めてから、密粒度アスコン（t=40mm）で表層を舗装します。路盤は 8/10・9/26・10/5〜9 に施工（10/5〜9 は予定欄）。施工体制台帳では舗装の協力会社の工期が 10/12 から始まっています。
   - 数量：上層路盤 300m³／アスファルト表層 1,910.5m²／路面工内法仕上げ 149.6m²
   - 留意点：変更区間（約100m）は、補強土壁と追加の切土が終わってから路盤・舗装をします。アスファルトは気温5℃以下では施工しないのが原則なので、変更区間の舗装が12月以降になる場合は時期を協議してください。
7. 法面工（植生）
   - 切土法面に植生基材吹付、盛土法面に種子散布とムシロ張り、すき取り土を使う有機材種子散布、路肩の張芝。
   - 数量：植生基材吹付（t=5cm）1,205.5m²／種子散布 686.1m²／有機材種子散布 604.9m²／ムシロ張 686.1m²／張芝 529.1m²
   - 留意点：発注者の計画工程表では11月。すき取り土は使う前に体積を検収して監督員へ報告すること（特記仕様書）。
8. 防護柵・標識 → 出来形の確認・後片付け
   - ガードケーブル（第3号は 9/21〜23 に施工、第4号は補強土壁の上）、カーブミラー3基、警戒標識（ふくろう）・案内標識（くま）各2基。標識の基礎は 10/2〜3。最後に出来形の確認と後片付けをします。
   - 数量：ガードケーブル C種 141.8m／カーブミラー 3基／標識 4基

## 確認しておきたい点

- 補強土壁と路線スライドの設計変更が、残りの工程のいちばん大きな要素 旬報の出来高は 9/30 で69%（計画工程表の9月末は63%）と先行していますが、補強土壁（約30日）と追加の切土（約2,731m³）が変更待ちです。変更が11月に入ると、補強土壁の盛土と変更区間の舗装が冬にかかります。協議の決着日と、冬期の扱い（施工時期・寒中の盛土・舗装）を早めに確かめてください。
- 暗渠 φ450 の数量（14.6m）は、第11号（7.29m）と第13号（7.29m）の合計と合います。平面図の第10号（SP1075 φ450 L=9.72m）は今回の数量に入っていないので、前年度までに施工済みかどうか確かめてください。
- 盛土（路体）の数量が 1,984m³ と 5,654m³ の2行あります。5,654m³ は残土の運搬量（土砂1,101＋軟岩4,144＋すき取り土409＝5,654m³）と一致するので、残土処理場での敷均しと読めます。
